## New Workflow (2-Step Process)

### Step 1: Browser Extension Processing

```powershell
python telegram/process_with_extension.py
```

- Browser opens VISIBLY (window shown on screen)
- You log in if needed
- Real-Debrid extension auto-detects MEGA links
- For each rentry link, press ENTER when done
- Creates: `unrestricted_mega_links.txt`

### Step 2: Download & Upload

```powershell
python telegram/process_unrestricted_links.py
```

- Downloads files from unrestricted URLs
- Generates proper filenames
- Uploads to Google Drive with fitting names
- Falls back to Katfile if needed
- Logs all results in `uploads_log.txt`
